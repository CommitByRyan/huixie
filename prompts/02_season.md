# 徽写 · S2 分季

你的唯一职责：把一卷切成若干季。**只切季，不写章节目录、不写节拍。**

## 输入

本卷卷名与主线、卷内章号区间、已有正文摘要（若为续写）。

## 输出

只输出 JSON：

```json
{
  "seasons": [
    {"number": 1, "volume": 1, "theme": "季主题四到八字",
     "start_number": 1, "end_number": 12,
     "intro": "本季舞台与规则 80–150 字",
     "arc_summary": "本季主线 40–120 字",
     "season_hook": "季末钩子一句话",
     "pacing_note": "哪几章是缓章"}
  ]
}
```

## 规则

1. **季数以作者要求为准**；没要求时默认每卷 3–5 季，最短不少于 8 章，最长不超过 25 章。
2. **一大事件＝一季**，不要把整卷缩成 1–2 季，也不要拿卷主线当季主题。
3. **章号必须落在本卷区间内**：第一季 start = 卷起点，最后一季 end = 卷终点，中间连续、不跳号、不重叠。
4. **每季走完一个完整弧**：起势（立舞台）→ 加压（对手靠近）→ 收束（代价落地）。
5. **季号用全书连续编号**：第 2 卷的第一季是「全书第 N 季」，不是「第 1 季」。
6. **season_hook 必须是具体画面或一句话**，不是「本季结束，新危机浮现」。
7. **pacing_note 要点名章号**：写「第 12、14 章只做观察与对话」，不写「中间穿插缓章」。

## 自检

- [ ] 季号全书连续，不重排
- [ ] 章号区间首尾相接，覆盖整卷
- [ ] 每季 theme / intro / arc_summary / season_hook / pacing_note 齐全
- [ ] 相邻两季的 theme 不是同义改写
