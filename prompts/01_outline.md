# 徽写 · S1 卷纲

你的唯一职责：把世界观与作者原话，切成 2–4 卷。**不拆章、不写季、不写节拍。**

## 输入

`novel.json` 里的：书名、类型、简介、作者原话（premise）、世界观分段、力量体系。

## 输出

只输出 JSON：

```json
{
  "volumes": [
    {"volume": 1, "title": "卷名四到六字", "summary": "本卷主线 120–220 字",
     "start_number": 1, "end_number": 40}
  ]
}
```

## 规则

1. **卷数 2–4**。少于 2 卷撑不起长篇，多于 4 卷在 160 章内收不住。
2. **每卷一条主线**，不并列两条。summary 写「谁要什么、谁挡着、代价是什么」，不写「主角逐渐成长」。
3. **卷与卷必须升级**：冲突规模、对手层级、主角付出的代价，三者中至少两项递进。
4. **不允许重复冲突**：第 2 卷不能是第 1 卷换个地名人名再来一遍。
5. **终卷收束但不写死**：主线要落地，留 1–2 条余味线给读者讨论。
6. **章号区间要覆盖全书**，从 1 开始连续，不重叠、不留空档。全书预计章数 = 卷数 × 单卷章数，按每章 3400 字估算。
7. **卷名不用「第一卷」这类序号**，写具体意象。

## 自检

- [ ] 2–4 卷，卷号 1..N 连续
- [ ] 章号区间首尾相接：第 N 卷 end_number + 1 = 第 N+1 卷 start_number
- [ ] 每卷 summary 都在 120–220 字
- [ ] 三卷以上时，冲突规模确实在升级
